# Free Fire · 活动内容监控平台

包含两种类型、五个活动的 14 天交互原型。玩家、行为、奖励和社区/游戏内反馈均为模拟数据。

## 体验

GitHub 仓库：https://github.com/oldsix1026-png/free-fire-activity-monitor

网站文件已预构建在 `dist/`，下载仓库后直接运行下方命令即可查看，无须安装依赖。

本机预览：http://127.0.0.1:4317 。如需重启，在项目目录运行：

```powershell
node ./serve.mjs
```

活动包含任务链「滑轨试炼」「协同突击」，以及按天独立解锁的「地图探索日历」「CS 每日热身」「战术补给日历」。

推荐路径：活动概览 → 选择滑轨试炼 → 数据表现查看 01/02/03 趋势 → 预警提示选择 T2 或第 8 天起体验率偏低 → 查看受影响玩家/玩家观测 → 行为时间线和相关反馈 → 返回预警保存处理记录。

选择地图探索日历后，任务追踪改为 14 天清单；可直接点击 D8、D9 查看当前完成率和未完成玩家。

## 六个功能

- 活动概览：类型筛选、五个活动卡片、近期参与结论、每日参与人数折线图。
- 数据表现：01 有效体验、02 任务超时、03 再次体验；指标导航、时间趋势与占比。
- 任务追踪：任务链/每日清单，当前完成率、任务条件、进度及玩家下钻。
- 玩家观测：中途停滞、领奖后未继续、已解锁未尝试；新/老/回流对比；模拟反馈筛选和关联行为。
- 预警提示：节点与日期异常、基于模拟证据的 AI 原因判断、建议调整、处理记录及恢复记录。
- 使用指南：操作手册、指标算法、数据来源与刷新规则。

柔和分区底色和玻璃胶囊导航适配桌面及窄屏。算法说明集中在使用指南。

## 刷新和筛选

从第 14 天 12:00 开始回放，每 5 分钟推进一次模拟进度；重新打开接续回放，活动结束后保留最终快照。处理记录与时钟保存在当前浏览器。

全局筛选影响当前活动。玩家观测的路径、任务和反馈筛选作用于对应模块。由日期预警进入观测时保留明确的日期范围标签，返回预警保留原选择与处理记录。明细面板固定打开时的数据快照，可点击「查看最新数据」更新。

## 数据口径

有效体验转化：曝光后 24 小时内有效体验人数 / 曝光满 24 小时人数。再次体验：首次有效体验后 24 小时内另一局再次体验人数 / 首次体验满 24 小时人数。

任务超时率只使用解锁满统计时长的玩家，迟到完成仍计超时；任务追踪的完成率使用当前已解锁人数，迟到完成计入完成。按天活动不依赖前一天完成。各活动的有效体验与各节点任务条件分别定义。

预警演示阈值：体验低于 65%，任务超时高于 25%，再次体验低于 50%；至少 30 人，连续三个独立五分钟时点满足。日期预警需要至少连续两个成熟日期队列越线。

典型路径基于实际事件分组；停滞和领奖中断需要至少 48 小时无新活动行为。意见卡片及 AI 分析均为模拟展示，原型不连接社区 API、不修改游戏配置、不发送外部消息。

## 开发与验证

```powershell
node ./verify.mjs
node ./verify-alerts.mjs
```

界面代码在 `src/content/dashboard/`，原始模拟数据在 `src/data.json`，预览构建在 `dist/`。`generate-platform.mjs` 负责五活动数据生成，数据字典见 `PLATFORM-DATA.md`。重新生成后需要重建；最终交付前将数据快照的 `buildStatus` 设为 `complete`。

共享 Data 运行时、来源菜单和编辑能力保持不变。
